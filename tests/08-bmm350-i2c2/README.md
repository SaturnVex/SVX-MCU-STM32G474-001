# BMM350 I2C2 Magnetometer Test

**Board:** `SVX-MCU-STM32G474-001` · **MCU:** STM32G474RBT6

Verify BMM350 I2C2 magnetometer data, interrupt and status LEDs.

## Files

- [Test setup, connections, import/build and acceptance guide (PDF)](SaturnVex_STM32G474_BMM350_Test_Guide_EN.pdf)
- [STM32CubeIDE source project (ZIP)](STM32G474_BMM350_I2C2_SaturnVex.zip?raw=true)

## Run this test

1. Read the PDF guide and confirm the hardware connections and prerequisites.
2. Download and extract `STM32G474_BMM350_I2C2_SaturnVex.zip`, preserving the project files.
3. Import into STM32CubeIDE, clean/build and flash via ST-LINK, following the guide.
4. Verify the results using the PDF acceptance criteria.
