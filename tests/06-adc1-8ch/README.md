# ADC1 8-Channel & LED Test

**Board:** `SVX-MCU-STM32G474-001` · **MCU:** STM32G474RBT6

Read eight ADC1 channels and display diagnostic values via USART2.

## Files

- [Test setup, connections, import/build and acceptance guide (PDF)](SaturnVex_STM32G474_ADC1_8CH_Test_Guide_EN_Final.pdf)
- [STM32CubeIDE source project (ZIP)](STM32G474_ADC1_8CH_LED_SaturnVex.zip?raw=true)

## Run this test

1. Read the PDF guide and confirm the hardware connections and prerequisites.
2. Download and extract `STM32G474_ADC1_8CH_LED_SaturnVex.zip`, preserving the project files.
3. Import into STM32CubeIDE, clean/build and flash via ST-LINK, following the guide.
4. Verify the results using the PDF acceptance criteria.

The ZIP is the original supplied project archive. Preserve third-party licenses and copyright notices.
